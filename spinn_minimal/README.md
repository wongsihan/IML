# SPINN - 最小化版本

这是SPINN论文的核心实现，只包含必要的文件。

## 核心文件

- `cavity_lubin_slip.py` - 主要论文实现
- `common_nomayavi.py` - 通用工具函数
- `spinn2d_nomayavi.py` - 2D SPINN实现
- `pde2d_base_nomayavi.py` - 2D PDE基类

## 使用方法

```bash
python cavity_lubin_slip.py
```

这将运行论文的主要结果。

## 论文引用

D. Wang, S. Wang, D. Kong, J. Wang, W. Li and M. Pecht, "Physics-Informed Sparse Neural Network for Permanent Magnet Eddy Current Device Modeling and Analysis," in IEEE Magnetics Letters, vol. 14, pp. 1-5, 2023.
